## 🚀 Инструкция по запуску тестов

### 1️⃣ Установка зависимостей

Убедитесь, что находитесь в корне проекта, и выполните:

```bash
pip install -r requirements.txt
```

---

### 2️⃣ Запуск всех тестов с генерацией отчёта Allure

```bash
pytest tests --alluredir=allure-results
```

---

### 3️⃣ Просмотр отчёта в HTML-формате

```bash
allure serve allure-results
```

💡 *После выполнения команды откроется локальный сервер с интерактивным отчётом в браузере.*
